# 教学管理系统前端

## 项目简介
基于阿里云平台的教学管理系统前端项目，采用 Vue 3 + Vite + Element Plus 开发。

## 功能模块
- 用户管理（学生、教师、管理员）
- 课程管理
- 作业管理
- 实验管理
- 排班管理
- 资源管理

## 技术栈
- Vue 3
- Vite
- Vue Router
- Pinia
- Axios
- Element Plus

## 安装依赖
```bash
npm install
```

## 运行开发环境
```bash
npm run dev
```

## 构建生产版本
```bash
npm run build
```
