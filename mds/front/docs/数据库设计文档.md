# 教学管理系统数据库设计文档

## 1. 概述

本文档描述了基于阿里云平台的教学管理系统的数据库设计方案，采用MySQL 8.0+作为关系型数据库管理系统。

### 1.1 设计原则
- 规范化设计，满足第三范式要求
- 合理冗余，提高查询性能
- 索引优化，加速常用查询
- 数据完整性约束
- 支持高并发访问

### 1.2 技术栈
- 数据库：MySQL 8.0+
- 字符集：utf8mb4
- 排序规则：utf8mb4_unicode_ci
- 存储引擎：InnoDB

---

## 2. ER图概述

### 2.1 核心实体
1. **用户 (User)**: 系统所有用户的基础信息
2. **学生 (Student)**: 学生特有信息
3. **教师 (Teacher)**: 教师特有信息
4. **管理员 (Admin)**: 管理员特有信息
5. **课程 (Course)**: 课程基础信息
6. **选课记录 (Course_Selection)**: 学生选课关系
7. **作业 (Homework)**: 作业信息
8. **作业提交 (Homework_Submission)**: 学生作业提交记录
9. **实验 (Experiment)**: 实验信息
10. **实验报告 (Experiment_Report)**: 学生实验报告
11. **教学资源 (Resource)**: 教学资源信息
12. **课程表 (Schedule)**: 排课信息
13. **公告通知 (Announcement)**: 系统公告

### 2.2 核心关系
- 用户(1) -- (0..1) 学生/教师/管理员
- 教师(1) -- (N) 课程
- 学生(M) -- (N) 课程 (通过选课记录)
- 课程(1) -- (N) 作业
- 课程(1) -- (N) 实验
- 课程(1) -- (N) 教学资源
- 课程(1) -- (N) 课程表

## 3. 数据表设计

### 3.1 用户表 (tb_user)

**功能说明**: 存储系统所有用户的公共信息

| 字段名 | 数据类型 | 约束 | 说明 |
|--------|---------|------|------|
| id | BIGINT | PRIMARY KEY, AUTO_INCREMENT | 用户ID |
| username | VARCHAR(50) | UNIQUE, NOT NULL | 登录账号 |
| password | VARCHAR(255) | NOT NULL | 密码(BCrypt加密) |
| role | ENUM('student','teacher','admin') | NOT NULL | 用户角色 |
| real_name | VARCHAR(50) | NOT NULL | 真实姓名 |
| gender | ENUM('male','female') | DEFAULT 'male' | 性别 |
| email | VARCHAR(100) | UNIQUE | 邮箱 |
| phone | VARCHAR(20) | | 手机号 |
| avatar | VARCHAR(255) | | 头像URL |
| status | ENUM('active','inactive') | DEFAULT 'active' | 账户状态 |
| create_time | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| update_time | DATETIME | DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

**索引设计**:
- PRIMARY KEY: `id`
- UNIQUE INDEX: `idx_username` (username)
- UNIQUE INDEX: `idx_email` (email)
- INDEX: `idx_role_status` (role, status)

### 4.2 级联删除策略

- **CASCADE**: 删除主表记录时自动删除从表相关记录
  - 适用于: 用户-学生/教师/管理员、课程-作业、课程-实验等
  
- **RESTRICT**: 如果从表有相关记录则禁止删除主表记录
  - 适用于: 教师-课程(防止误删有课程的教师)

## 5. 冗余优化策略

### 5.1 冗余字段设计

| 表名 | 冗余字段 | 冗余原因 | 更新策略 |
|------|---------|---------|---------|
| tb_course | teacher_name | 课程列表频繁展示教师名，避免JOIN | 教师姓名变更时触发器更新 |
| tb_course_selection | student_name, course_name | 选课记录查询频繁，减少JOIN | INSERT时填充，很少变更 |
| tb_homework | course_name | 作业列表展示，避免JOIN课程表 | 课程名变更时触发器更新 |
| tb_homework_submission | student_name, student_number | 教师批改时快速展示学生信息 | INSERT时填充 |
| tb_experiment | course_name | 实验列表展示 | 触发器更新 |
| tb_experiment_report | student_name, student_number | 报告查看时快速展示 | INSERT时填充 |
| tb_resource | course_name, uploader_name | 资源浏览时高频查询 | 触发器更新 |
| tb_schedule | course_name, teacher_name | 课程表展示优化 | 触发器更新 |
| tb_announcement | publisher_name | 公告列表展示 | INSERT时填充 |

### 5.2 计数器字段优化

| 表名 | 计数字段 | 更新方式 | 说明 |
|------|---------|---------|------|
| tb_course | enrolled | 触发器/应用层更新 | 选课时+1，退课时-1 |
| tb_resource | download_count | 应用层更新 | 下载时+1，使用Redis缓存批量更新 |

### 5.3 反范式化决策

**冗余收益**:
- 减少70%的JOIN操作
- 查询性能提升约3-5倍
- 降低数据库负载

**冗余代价**:
- 存储空间增加约15%
- 需要触发器维护数据一致性
- 更新操作略微增加复杂度

## 6. 索引优化策略

### 6.1 索引类型选择

| 索引类型 | 适用场景 | 示例 |
|---------|---------|------|
| 主键索引 | 唯一标识 | id |
| 唯一索引 | 业务唯一约束 | username, email, student_number |
| 普通索引 | 频繁查询字段 | role, status, course_id |
| 组合索引 | 多条件查询 | (role, status), (semester, status) |
| 全文索引 | 文本搜索 | 资源名称搜索 |

### 6.2 索引设计原则

1. **高选择性字段优先**: 如student_number, email
2. **覆盖索引优化**: 包含查询所需所有字段
3. **避免过多索引**: 单表不超过6个索引
4. **左前缀原则**: 组合索引字段顺序重要
5. **定期维护**: 重建碎片化索引

### 6.3 慢查询优化建议

```sql
-- 1. 课程列表查询(教师视角)
SELECT id, name, semester, capacity, enrolled 
FROM tb_course 
WHERE teacher_id = ? AND status = 'approved'
ORDER BY semester DESC;
-- 索引: idx_teacher_id, idx_semester_status

-- 2. 学生选课列表
SELECT cs.*, c.teacher_name, c.semester 
FROM tb_course_selection cs
INNER JOIN tb_course c ON cs.course_id = c.id
WHERE cs.student_id = ? AND cs.status = 'selected';
-- 索引: idx_student_course, idx_course_id

-- 3. 待批改作业统计
SELECT COUNT(*) 
FROM tb_homework_submission 
WHERE homework_id IN (
    SELECT id FROM tb_homework WHERE course_id = ?
) AND status = 'submitted';
-- 索引: idx_homework_student, idx_status

-- 4. 资源全文搜索
SELECT * FROM tb_resource 
WHERE MATCH(name) AGAINST('Java' IN NATURAL LANGUAGE MODE)
AND type = 'document' AND status = 'approved';
-- 索引: idx_fulltext_name, idx_type_status
```
