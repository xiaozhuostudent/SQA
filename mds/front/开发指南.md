# 教学管理系统开发指南

## 项目概述

基于阿里云平台的教学管理系统，采用前后端分离架构：
- **前端**: Vue 3 + Vite + Element Plus
- **后端**: Spring Boot（待开发）
- **数据库**: MySQL
- **云服务**: 阿里云 OSS（文件存储）、ECS（云服务器）

## 功能模块说明

### 学生端功能
1. **首页仪表盘**: 显示课程、作业、实验统计，待办事项
2. **我的课程**: 选课、退课、查看课程信息
3. **课程作业**: 查看作业、提交作业、查看成绩
4. **实验管理**: 在线实验、提交实验报告
5. **学习资源**: 浏览和下载课程资源
6. **个人信息**: 查看和修改个人信息

### 教师端功能
1. **首页仪表盘**: 显示教学统计、本周课程安排
2. **课程管理**: 创建、编辑、删除课程
3. **作业管理**: 布置作业、批改作业
4. **实验管理**: 创建实验、管理实验环境
5. **教学资源**: 上传和管理教学资源
6. **个人信息**: 查看和修改个人信息

### 管理员端功能
1. **首页仪表盘**: 系统总体统计
2. **用户管理**: 创建、编辑、删除用户，重置密码
3. **课程管理**: 查看和管理所有课程
4. **排班管理**: 创建和管理课程排班，冲突检测
5. **资源管理**: 管理所有教学资源
6. **统计分析**: 查看系统使用统计

## 开发注意事项

1. **前后端联调**
   - 前端代理配置已在 `vite.config.js` 中设置
   - 后端需要配置CORS允许跨域访问

2. **认证机制**
   - 使用JWT Token进行身份认证
   - Token存储在localStorage中
   - 所有需要认证的接口都需要在请求头中携带Token

3. **文件上传**
   - 建议使用阿里云OSS存储文件
   - 前端直接上传到OSS，后端只保存文件信息

4. **实验环境**
   - 可以集成阿里云容器服务或云IDE
   - 提供在线编程和调试功能

5. **安全建议**
   - 密码使用BCrypt加密
   - 敏感操作记录操作日志
   - 接口做防刷限流
