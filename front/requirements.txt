# ==================== 安装说明 ====================

# 1. 确保已安装 Node.js (推荐 v16.x 或更高版本)
# 2. 在项目根目录执行以下命令安装所有依赖:
#    npm install
#
# 3. 或者使用 yarn:
#    yarn install
#
# 4. 或者使用 pnpm (推荐,更快速):
#    pnpm install

# ==================== 运行说明 ====================

# 开发环境运行:
#   npm run dev

# 生产环境构建:
#   npm run build

# 预览生产构建:
#   npm run preview

# ==================== 依赖包说明 ====================

# vue (^3.3.4)
#   - 渐进式 JavaScript 框架
#   - 用于构建用户界面

# vue-router (^4.2.4)
#   - Vue 官方路由管理器
#   - 支持单页面应用的路由功能

# pinia (^2.1.6)
#   - Vue 3 官方推荐的状态管理库
#   - 替代 Vuex,更轻量和类型安全

# axios (^1.5.0)
#   - 基于 Promise 的 HTTP 客户端
#   - 用于浏览器和 Node.js 的 HTTP 请求

# element-plus (^2.4.0)
#   - 基于 Vue 3 的 UI 组件库
#   - 提供丰富的企业级 UI 组件

# @element-plus/icons-vue (^2.1.0)
#   - Element Plus 配套的图标库
#   - 提供大量可用的 SVG 图标

# echarts (^5.4.3)
#   - Apache ECharts 数据可视化库
#   - 用于管理员统计页面的图表展示

# vite (^4.4.9)
#   - 下一代前端构建工具
#   - 提供极速的开发服务器和优化的生产构建

# @vitejs/plugin-vue (^4.3.4)
#   - Vite 的 Vue 3 官方插件
#   - 支持 Vue 单文件组件 (SFC)

# ==================== 项目特点 ====================

# 1. 使用 Vue 3 Composition API
# 2. 采用 Vite 作为构建工具,开发体验极佳
# 3. Element Plus 提供完整的 UI 组件支持
# 4. Pinia 进行状态管理
# 5. 前端 Mock 登录系统,无需后端即可测试
# 6. 三角色系统:学生、教师、管理员
