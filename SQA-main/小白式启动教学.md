# 快速开始指南

## 🎯 给别人使用的简单说明

如果你拿到了这个项目代码，按照以下步骤即可快速启动。

---

## Windows 用户

### 📋 准备工作
1. 安装 [Docker Desktop](https://www.docker.com/products/docker-desktop) 
2. 安装 [Python 3](https://www.python.org/downloads/)（安装时勾选"Add Python to PATH"）
3. 启动 Docker Desktop

### 🚀 启动项目

#### Windows 用户
**方法 1: 双击启动（最简单）⭐**
- 双击 `start.bat` 文件
- 脚本会自动检查 Python 和 Docker
- 如果环境符合要求，自动启动所有服务
- 等待 5-10 分钟（首次启动需要下载和构建）

**方法 2: 命令行启动**
```cmd
python start.py
```

#### macOS / Linux 用户
```bash
# 方法 1: 使用 Python 脚本（推荐）
python3 start.py

# 方法 2: 使用 Shell 脚本
./start.sh
```

**启动流程**:
1. ✅ **自动检查** Python 版本（需要 3.7+）
2. ✅ **自动检查** Docker 是否安装和运行
3. ✅ 如果环境正常 → **自动启动**所有服务
4. ❌ 如果环境有问题 → 显示安装指南

**完全自动化，无需手动操作！**

---

## macOS 用户

### 📋 准备工作
1. 安装 [Docker Desktop](https://www.docker.com/products/docker-desktop)
2. macOS 已自带 Python 3
3. 启动 Docker Desktop

### 🚀 启动项目
打开终端，执行：
```bash
# 方法 1: 使用 Python 脚本（推荐）
python3 start.py

# 方法 2: 使用 Shell 脚本
./start.sh
```

**说明**:
- 脚本会**自动检测**是否安装 Docker
- 如果有 Docker → 自动使用 Docker 启动（推荐）
- 如果没有 Docker → 使用本地模式启动
- **无需手动选择，全自动！**

sudo apt-get install docker.io docker-compose python3

# 启动 Docker

## ❓ 常见问题

### Q1: 提示 Python 版本过低
**A**: 
- 下载并安装 Python 3.7 或更高版本
- 下载地址: https://www.python.org/downloads/
- 安装时勾选 "Add Python to PATH"

### Q2: 提示 Docker 未安装
**A**: 
- 下载并安装 Docker Desktop
- 下载地址: https://www.docker.com/products/docker-desktop
- 安装后启动 Docker Desktop 应用

### Q3: 提示 Docker 未运行
**A**: 
- Windows/macOS: 双击打开 Docker Desktop 应用
- Linux: `sudo systemctl start docker`
- 等待 Docker 启动后重新运行脚本

### Q4: 端口被占用
**A**: 
- 关闭占用 8080, 3001, 5051 端口的程序
- 或者修改 `docker-compose.yml` 中的端口配置

### Q5: 启动很慢
**A**: 
- 首次启动需要下载依赖，正常需要 5-10 分钟
- 后续启动只需要 1-2 分钟

### Q6: 服务无法访问
**A**: 
```bash
# 查看服务状态
docker-compose ps

# 查看日志
docker-compose logs -f
```
